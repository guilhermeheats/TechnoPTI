# Documentação em PDF

Esta página reúne os PDFs oficiais do projeto. A documentação **atualizada** é
este site MkDocs; os PDFs servem para consulta offline, impressão e backup da
apresentação.

## Documentação técnica completa

A documentação técnica de **36 páginas** cobre arquitetura, frontend, backend,
banco e fluxo de desenvolvimento. Ela é um registro de consulta e pode estar
levemente defasada em relação a este site.

!!! tip "PDF atualizado"

    Para gerar um PDF da documentação atual, abra a página desejada neste site
    e use **Ctrl+P** (Windows/Linux) ou **Cmd+P** (macOS). A versão em PDF de
    36 páginas continua disponível para consulta e impressão offline.
