# Protótipos antigos

Esta pasta guarda os primeiros protótipos de banco e de teste (`main.py` e
`teste.py`). Eles **não fazem parte da aplicação em execução** e foram mantidos
apenas para histórico.

O código ativo está em:

- `../` — API Flask, modelos, solver e banco;
- `../../frontend/` — interface React.
